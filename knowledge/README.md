# Knowledge

Short notes worth keeping across projects: how a system works, a debugging trick, a decision and why.

- One topic per file: `knowledge/<topic>.md`, for example `knowledge/kafka-consumer-rebalance.md`.
- Start each note with a one-line summary, then the details, then links.
- Claude adds notes here through /reflect or the kit-capture skill. Search them with `rg <word> ~/claude-kit/knowledge`.
