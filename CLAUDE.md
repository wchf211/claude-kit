# claude-kit

This repo is Daniel's Claude Code kit. Every Claude project thread that opens it gets the kit's rules, skills and reviewer agents with no install step:

- Rules: @rules/global.md
- Skills: `.claude/skills` links to `skills/`
- Reviewer agents: `.claude/agents` links to `agents/`

On his own machines, `install.sh` sets up the same things for every project.
