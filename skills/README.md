# Skills

Each folder is one skill (`<name>/SKILL.md`). `install.sh` links every skill here into `~/.claude/skills/`, so all projects can use it.

| Skill | Use |
| ----- | --- |
| kit-capture | Save a rule, knowledge note, skill or idea into this kit |
| drive | Take a task from goal to verified result: brief, execute, self-check, short report |
| att-bills | Monthly AT&T family-bill update; reads the private README in ~/workspace/TODO |
