- Wrote `hosting-comparison.md` covering the Cybernews hosts, Netlify, Cloudflare, VPS, Supabase and domains. No repo changes.

### Learned
- A public repo exposes every file. Deploy only `site/` and keep private data behind one-time TOTP codes.
- Test with `netlify dev` first to save build credits. Local dev skips some headers, so verify headers on the real Netlify deploy.
- The Cybernews hosts are shared PHP on prepaid terms, so skip them. Cloudflare Workers with KV/D1 fits toy apps better than Netlify's shared credit pool.
- The Netlify move and the Cloudflare recommendation came from parallel sessions. The site is on Netlify, but the hosting choice is still open.

- Consider a pre-deploy hook or script for the bio site that runs `netlify dev` and checks that only `site/` files are published, before `netlify deploy --prod`.
